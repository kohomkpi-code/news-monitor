# KOHOM 뉴스룸 사용자 매뉴얼 (텍스트판)

- 대상 앱: KOHOM 뉴스룸 v1.0.8 (언론보도 모니터링 앱, 윈도우 PC용)
- 작성: 2026. 10. 26. · 주택관리공단 전략과
- 이 문서는 그림 없이 글만으로 앱을 처음부터 끝까지 쓸 수 있게 정리한 것입니다. 버튼 이름은 앱 화면의 글자 그대로 `[ ]` 안에 적었습니다.
- 그림이 들어간 매뉴얼: `2026_KOHOM뉴스룸_사용자매뉴얼_설명자료.pptx`(상세), `2026_KOHOM뉴스룸_한장요약_설명자료.pptx`(한 장 요약)

## 1. 앱 소개

### 1-1. 한 줄 요약
구글 뉴스와 전문지에서 공단 관련 기사를 모아, 선정 규칙으로 점수를 매기고, 임원 보고용 기사 5건을 추천한 뒤, 그룹웨어 메일에 붙여 넣을 보고서를 만들어 주는 프로그램입니다.

### 1-2. 앱이 하는 일 (6단계)
1. **모으기** — 구글 뉴스와 전문지 RSS에서 키워드로 기사를 모읍니다.
2. **거르기** — 제목에 키워드가 실제로 있는지 다시 확인하고, 해외·무관 매체, 단순 행사 기사, 이미 보고한 기사를 뺍니다. 여러 매체가 같은 사안을 쓴 기사는 하나로 묶습니다.
3. **점수·분류** — 공단 이름, 공단 사업을 가리키는 말, 리스크 단어 등으로 점수를 매기고 분류(리스크·기관 직접 등)를 추정합니다.
4. **추천** — 리스크 기사 먼저, 분류가 고르게 5건을 추천(★)합니다.
5. **보고서** — 메일에 붙여 넣을 제목과 본문을 만들어 브라우저로 엽니다.
6. **기록** — 보낸 기사를 기록해 두어, 다음 조회에서 자동으로 뺍니다.

그리고 **환류**: 결과를 엑셀로 내려받아 Claude에 보내면 규칙 개선안이 돌아오고, 이를 앱에 붙여 넣어 규칙을 고칩니다. 앱을 업데이트하지 않아도 다음 조회부터 반영됩니다.

### 1-3. 누가 어떤 탭을 쓰나
| 사용자 | 주로 쓰는 탭 |
|---|---|
| 일반 직원(매일 보고) | 베이직, 보고 기록 |
| 언론보도 담당자 | 프로, 선정 규칙, 설정 |

## 2. 설치와 첫 실행

### 2-1. 내려받기
1. GitHub Releases 또는 공문에 안내된 경로에서 `NewsMonitor_v버전.exe`(예: `NewsMonitor_v1.0.8.exe`)를 받습니다.
2. 적당한 폴더(예: `C:\NewsMonitor\`)에 넣고 더블클릭해 실행합니다. 설치 과정은 없습니다.

### 2-2. 윈도우 경고가 뜰 때
처음 실행할 때 "Windows의 PC 보호" 경고가 뜰 수 있습니다. 코드 서명이 없는 프로그램이라 뜨는 안내입니다.
- 방법 1: 경고 창에서 **[추가 정보]** → **[실행]**
- 방법 2: exe 파일 **오른쪽 클릭 → 속성 → 아래 '차단 해제' 체크 → 확인**. 이후에는 경고가 뜨지 않습니다.

### 2-3. 저장되는 파일
exe와 같은 폴더에 자동으로 생기며, 모두 내 PC에만 저장되고 어디로도 보내지 않습니다.
| 파일·폴더 | 내용 |
|---|---|
| `config.json` | 설정과 선정 규칙, 규칙 변경 이력 |
| `sent_history.json` | 보고 완료 기록(3년 보관) |
| `reports\` | 만든 HTML 보고서 |

### 2-4. 업데이트
- 앱을 켤 때 새 버전이 있으면 알려 줍니다. **[예]**를 누르면 새 파일을 받아 스스로 바꾸고 다시 켜집니다. 설정과 기록은 그대로 남습니다.
- 언제든 화면 오른쪽 위 **[업데이트 확인]**으로 직접 확인할 수 있습니다.
- GitHub 접속이 막힌 PC에서는 "GitHub에 접속할 수 없어 새 버전을 확인하지 못했습니다" 안내가 뜹니다. 공문에 안내된 경로에서 새 exe를 받아 지금 파일과 바꾸면 됩니다.
- 업데이트하면 파일 이름이 새 버전으로 바뀌므로 바탕화면 바로가기는 다시 만들어야 합니다.

## 3. 화면 구성

### 3-1. 위쪽 머리띠
- 왼쪽: 앱 이름과 버전(`KOHOM 뉴스룸 v1.0.8`)
- 가운데: 탭 5개 — **베이직 · 프로 · 보고 기록 · 선정 규칙 · 설정**
- 오른쪽: **[업데이트 확인]**

### 3-2. 아래쪽 상태줄
지금 무슨 일이 일어나는지 한 줄로 보여 줍니다.
- 진행 중: 앰버(주황) 막대와 "구글 뉴스 검색 중 · 키워드 12/67 …"
- 완료: "조회 완료" + 건수 흐름(예: 수집 19건 → 제외 매체 1건 제외 → 제목 검증 1건 제외 → … → 표시 15건 · ★추천 5건)
- 오류: 상태줄 전체가 빨갛게 바뀌고 오류 내용 표시

### 3-3. 창 크기
최소 980×640입니다. 창을 키우면 표에 더 많은 기사가 보입니다.

## 4. 베이직 탭 — 매일 보고 4단계

화면 맨 위에 **① 조회 → ② 추천 확인 → ③ 보고서 열기 → ④ 보고 완료로 기록** 단계가 표시됩니다. 끝난 단계는 ✓, 지금 할 단계는 진하게 보이고, 다음에 누를 버튼 하나만 진한 남색입니다.

### 4-1. ① 조회
1. **조회 기간**은 **[자동]**이 기본입니다: 직전 영업일 오전 9시 ~ 지금(공휴일 반영). 필요하면 **[오늘]**, **[최근 3일]**을 누르거나 날짜 칸을 직접 고칩니다(형식: `2026-10-23 09:00` ~ `2026-10-26`).
2. **[① 조회]**를 누릅니다. 키워드별로 구글 뉴스와 전문지를 차례로 묻고, 1~2분쯤 걸립니다(추정).
3. 설정을 빠뜨린 것이 생각나면 **[■ 정지]**를 누릅니다. 지금 묻고 있는 키워드 하나가 끝나면 멈추고, 멈춘 조회의 기사는 표에 넣지 않습니다. 정지 버튼은 조회 중에만 켜집니다.

### 4-2. ② 추천 확인과 순서 정하기
조회가 끝나면 표에 후보 기사가 나오고, **★추천 5건이 미리 선택(☑)**되어 맨 위에 옵니다.

표의 열: 선택 · 순번 · 날짜 · 매체 · 제목
- **선택 칸**(맨 왼쪽): 누르면 넣고 빼기. ★는 앱이 추천한 기사.
- **순번**: 조회할 때 매긴 고정 번호. 정렬하거나 순서를 바꿔도 그대로입니다(프로 탭 AI 선별의 번호와 같음).
- **제목**: 더블클릭하면 기사 원문이 브라우저로 열립니다.
- 줄 바탕색: 연한 주황 = 공단(A) 기사, 연한 청록 = 직접 추가한 기사.

순서 바꾸기(보고서에 이 순서대로 실립니다):
- **끌어 놓기**: 체크 칸이 아닌 곳(제목·매체 등)을 누른 채 위아래로 끌어 원하는 자리에 놓습니다. 표 끝으로 끌면 화면이 저절로 넘어갑니다.
- **[▲] [▼]**: 줄을 한 번 누른 뒤 한 칸씩 이동합니다(키보드 Ctrl+↑, Ctrl+↓).

그 밖의 버튼:
- **[↻ 추천으로 되돌리기]**: 고친 선택을 처음 추천대로 돌립니다.
- **[＋ 기사 링크로 추가]**: 검색에 없는 기사를 넣습니다. 기사 주소를 붙여 넣고 **[불러오기]** → 제목·매체·날짜가 채워지면 확인 후 **[추가]**. 직접 추가한 기사는 맨 위에 선택된 채로 들어가고 항상 보고서에 포함됩니다.

선택 건수는 표 위 "선택 N건 / 후보 M건"에 보입니다.

### 4-3. ③ 보고서 열기
1. **[③ HTML 보고서 열기 (메일용)]**를 누르면 브라우저에 보고서 화면이 열립니다. 원문 주소를 찾느라 몇 초 걸릴 수 있습니다.
2. 보고서 화면 구성:
   - **메일 제목**: 예) `(261026)언론보도` — **[제목 복사]**
   - **본문 ① 기존 양식**: 링크 걸린 기사 제목만, 표 순서대로 — **[본문 복사]**
   - **본문 ② 분류·인사이트 포함**: 분류(또는 키워드)별 묶음, 매체·날짜, AI 인사이트 — **[본문 복사]**
3. 그룹웨어 편지쓰기에서 제목 칸에 Ctrl+V, 본문 칸에 Ctrl+V(①·② 중 하나) → 받는 사람 지정 → 보내기. 본문 글자 크기는 16px로 붙습니다.
4. 원문 주소를 못 찾은 기사는 구글 경유 주소로 들어갑니다(상태줄에 건수 표시).

### 4-4. ④ 보고 완료로 기록
메일을 보낸 뒤 **[④ 보고 완료로 기록]** → 확인 창에서 **[예]**. 선택한 기사가 오늘 날짜로 기록되고, 다음 조회부터 '이미 보고한 기사'로 자동 제외됩니다.

## 5. 프로 탭 — 담당자용

베이직과 같은 기사를 보지만 **후보 전체가 선택된 채로** 시작하고, 등급·점수·분류를 보며 직접 고릅니다. 선택은 베이직과 따로입니다.

### 5-1. 조회 조건
- 체크 3개: **이미 보고한 기사 제외**, **같은 사안 기사 묶기**, **단순 행사 기사 제외 (A는 감점)**
- 조회 기간: **[자동] [오늘] [최근 3일] [최근 7일]**, **[■ 정지] [조회]**
- 키워드 요약 한 줄(예: A 기관 15 · S 사업어 22 · B 환경 30 · 제외어 7 · 제외 매체 18 · 추천 5건(30점 이상)) — 고치려면 **[선정 규칙에서 고치기 ›]**

### 5-2. 선택 도구
- **[전체 선택] [전체 해제] [★추천만]**
- **키워드별**: 목록에서 등급([등급 A] 전체 등)이나 키워드를 고른 뒤 **[선택] [해제] [이것만]**
- 오른쪽: 선택 N건 / 전체 건수

### 5-3. 순서 줄
- **[☑ 선택 항목 맨 위로]**: 선택한 기사를 지금 순서 그대로 맨 위로 모읍니다.
- **[▲ 위로] [▼ 아래로]**, 끌어 놓기 — 베이직과 같습니다.
- **[＋ 기사 링크로 추가]**
- 이 순서대로 보고서에 실립니다. 순서를 정한 뒤 표 머리글을 누르면 정렬되어 순서가 바뀌니 주의합니다.

### 5-4. 결과 표의 열
선택 · 순번 · 등급 · 점수 · 분류 · 키워드 · 날짜 · 매체 · 제목. 머리글을 누르면 그 열로 정렬, 다시 누르면 반대로.

**등급** — 왜 후보가 됐는지
| 등급 | 뜻 | 기본 점수 |
|---|---|---|
| A | 제목에 '주택관리공단'(또는 KOHOM) | +50 |
| A? | 지사명만 있고 공단 이름은 없음 — 공단 기사인지 확인 필요(추천 안 함) | +20 |
| S | 공단 업무를 가리키는 말(영구임대·공공임대·주거급여 등) | +30 (서로 다른 말 2개 이상 +40) |
| B | 주거·공동주택 정책 환경(LH·층간소음·경영평가 등) | +10 |
| 전문지 | 아파트관리신문·한국아파트신문 — 키워드 없이도 후보 | +15 |
| 직접 | [기사 링크로 추가]로 넣은 기사 — 항상 포함 | — |

**분류** — 무엇에 관한 기사인지(위에서부터 처음 맞는 것)
1. 리스크 — 리스크 단어(사고·체납·징계 등)가 공단 관련 주제와 함께
2. 기관 직접 — 공단(A) 기사
3. 정책·제도 — 개정·시행령 같은 정책 단어(주거·임대 주제), 주거급여 등 제도 이름
4. 모회사·부처 — LH·국토부 관련
5. 공공기관 공통 — 경영평가·청렴도·산하기관·중대재해
6. 업계·환경 — 그 밖(공고 기사 포함)

AI 선정 결과를 붙여 넣으면 AI가 정한 분류가 우선합니다.

### 5-5. AI 선별 (Claude 중계)
앱이 AI를 직접 부르지 않습니다. 담당자가 복사·붙여넣기로 이어 줍니다.
1. **[① AI 선별 요청문 복사]** — 선택된 기사들이 순번과 함께 복사됩니다.
2. 판단 기준서가 들어 있는 Claude 프로젝트 채팅에 Ctrl+V → 보내기.
3. Claude 답변의 `#선정` 아래 줄(형식: `번호|분류|한 줄 인사이트`)을 복사합니다. 답변 전체를 복사해도 됩니다.
4. **[② 선정 결과 붙여넣기]** → 창에 붙여 넣기 → "기사 N건을 찾았습니다" 확인 → **[적용]**.
5. 고른 기사만 선택되고 분류·인사이트가 붙어 맨 위로 옵니다. 필요하면 순서를 바꾼 뒤 **[③ HTML 보고서 열기]** → **[④ 보고 완료로 기록]**.

번호는 표의 '순번'과 같으므로, Claude가 "8번"이라고 하면 표에서 순번 8을 보면 됩니다.

### 5-6. 결과 엑셀 내려받기
프로 탭 왼쪽 아래 **[⤓ 결과 엑셀로 내려받기]** → 저장 위치(기본: 다운로드 폴더). 파일 이름: `KOHOM뉴스룸_조회결과_날짜_시분.xlsx`.
| 시트 | 담긴 것 |
|---|---|
| 조회결과 | 표의 기사 전부, 프로·베이직 최종 선택, ★추천, 등급, 점수와 항목별 점수, 점수 근거 한 줄, 자동 분류, AI 분류·인사이트, 키워드, 요약, 링크 |
| 빠진 기사 | 제외 매체·제목 검증 실패·제외어·단순 행사·이미 보고·같은 사안 묶음으로 빠진 기사와 이유 |
| 조회 조건 | 기간, 검색 방식, 전문지, 옵션, 건수 흐름 |
| 선정 규칙 | 조회한 그때의 규칙 전체(규칙 JSON 포함) |

네이버 키 같은 비밀값은 넣지 않습니다. 환류(7-6)의 재료로 씁니다.

## 6. 보고 기록 탭

- 위 안내 띠: **[＋ 지난 보고 메일 불러오기 (HTML)]**
- 왼쪽: 보고일 목록(날짜와 건수), **[↻ 새로고침]**
- 오른쪽: 고른 날의 머리(예: 10월 26일 (월) 보고 · 5건 · 13:16 기록), **[이 날 보고서 다시 열기 (메일용)]**, 기사 목록(기록 시각·매체·제목 — 더블클릭하면 원문)
- 아래: **[선택한 기사 기록 취소]** — 기사를 고른 뒤에만 켜집니다(Ctrl·Shift로 여러 개). 취소한 기사는 다음 조회에 다시 나옵니다.

**지난 보고 메일 불러오기**: 앱을 쓰기 전에 보낸 보고 메일도 기록으로 넣을 수 있습니다.
1. 그룹웨어에서 보낸 메일을 HTML(또는 EML·MHT)로 저장합니다.
2. **[＋ 지난 보고 메일 불러오기 (HTML)]** → 파일 여러 개 고르기.
3. 파일마다 찾은 보고일·시각·기사 수가 나옵니다. 보고일이 틀리거나 비었으면 그 줄을 더블클릭해 고칩니다.
4. **[불러오기]**. 이미 기록에 있는 기사는 건너뜁니다.

기록은 3년 보관되고, 지난 기록은 자동으로 지워집니다.

## 7. 선정 규칙 탭 — 키워드·점수·추천 기준

고치고 **[규칙 저장]**을 누르면 다음 조회부터 적용됩니다. 앱 업데이트가 필요 없습니다. 지금 표에 결과가 있으면 점수·분류·★추천을 바로 다시 계산합니다(키워드·거르기 규칙을 바꿨으면 다시 조회해야 반영).

### 7-1. 화면 구성(위에서 아래로)
- 안내 띠: 환류 순서 안내, **[개선 요청문 복사] [Claude 답변 붙여넣기]**
- ① 검색 키워드: A 기관 직접 · S 사업어 · B 환경 / A 지사명 · 단지명(S로 봄) · 제외어 / 지사명과 함께 있어야 하는 말 / 체크: 구글 뉴스 정확 검색(따옴표로 묻기) · B 키워드는 요약까지 확인 · S 사업어도 요약까지 확인 / 키워드당 최대 건수
- ② 거르기: 단순 행사어 · 제외 매체
- ③ 점수: 가중치 숫자 칸 / 모회사·부처어 · 리스크어 · 리스크 조건어 · 정책어 · 정책 조건어 · 공급·개발어 · 일상 공고어 · 전문지 · 키워드 면제 전문지 · 본사 지역지
- ④ 분류: 분류 순서 · 정책·제도어 · 공공기관 공통어
- ⑤ 추천 (베이직 ★): 추천 건수 · 추천 최소 점수 · 리스크 먼저 최대 · 공단(A) 최소 · 같은 분류 최대 · 업계·환경 최대
- 변경 이력: 최근 3건(바뀐 항목 이름만) + **[변경 이력 보기 (전체 N건)]**
- 맨 아래: **[규칙 파일 불러오기] [규칙 파일 내보내기] [기본값으로]**, **[규칙 저장]**

### 7-2. 키워드 쓰는 법
- 한 줄에 하나.
- 띄어 쓴 말은 **같은 순서로, 낱말 사이 20자 이내**에 있으면 맞습니다. 예) `공동주택 관리비` → "공동주택 관리비 공개"는 맞음, "관리비 오른 공동주택"은 안 맞음.
- 띄어쓰기는 무시합니다. 예) `부정입주` = "부정 입주".
- 같은 뜻은 **OR**로 한 줄에. 예) `승강기 OR 엘리베이터`.
- 뺄 말은 앞에 **-**. 예) `임대주택 -민간임대 -수요` (민간임대·수요가 있으면 안 맞음).
- `"따옴표"`로 묶으면 그 문구 그대로. 예) `"SH 임대주택"`.
- 한 글자 낱말은 다음 낱말과 붙여 봅니다. 예) `군 관사` = "군관사".
- 범용어 하나(예: 공공기관, 국정감사)는 수백 건을 끌어오니 두 말을 묶어 씁니다(예: `공공기관 경영평가`).
- 검색 키워드가 많을수록 조회가 느려집니다.

### 7-3. 점수(기본값, 숫자 칸에서 바꿈)
| 항목 | 점수 | 조건 |
|---|---|---|
| A 기관 직접 | +50 | 제목에 A 키워드 |
| 지사명만(A?) | +20 | 지사명만 있고 '주택관리공단'은 없음 |
| S 사업어 | +30 / 2개 이상 +40 | 제목 기준, 같은 글자를 함께 잡은 말은 1개로 셈 |
| 모회사·부처어 | +20 | LH·한국토지주택공사·국토부·국토교통부·국토위 |
| B 환경 | +10 | 요약까지 확인 |
| 리스크어 | +20 | A·S·모회사어·B(제목)·리스크 조건어(임대주택·공공임대·공동주택·입주민·관리사무소)·면제 전문지 중 하나와 함께일 때만 |

| 본사 지역지 | +2 | A 기사일 때만 |

| 일상 공고 | −25 | 모집·접수·공고 등, A 기사는 제외 |
| A 행사 | −20 | 공단 기사에 단순 행사어 |

### 7-4. 추천(★) 기준(기본값)
1. 리스크 기사를 점수순으로 먼저(최대 2건)
2. 공단(A) 기사가 없으면 최소 1건 넣기
3. 나머지는 점수순
- 같은 분류는 2건까지, 업계·환경은 1건까지
- 30점 미만, 지사명만(A?), 일상 공고(A 제외)는 추천하지 않음
- 그래서 5건이 안 차는 날도 있습니다(상태줄 "오늘은 ★추천 N건")
- 리스크 기사가 상한을 넘으면 상태줄에 "리스크 N건 중 2건 추천 — 나머지는 표에서 확인"
- 직접 추가한 기사는 5건과 별도로 항상 포함

### 7-5. 저장·이력·파일
- **[규칙 저장]**: 바뀐 항목이 변경 이력에 "언제 · 어떻게(직접 수정 등) · 무엇이"로 남습니다(최대 100건).
- **[변경 이력 보기]**: 전체 기록을 최근 것부터, 바뀐 내용 한 줄씩(예: "B 환경: 13 → 14", "S 사업어: +관리사무소").
- **[규칙 파일 내보내기]**: `KOHOM뉴스룸_선정규칙_날짜_시분.json`. 다른 PC에서 **[규칙 파일 불러오기]**로 같은 규칙을 씁니다.
- **[기본값으로]**: 앱의 기본 규칙으로 되돌립니다(바뀔 항목을 먼저 보여 줌).
- 앱 업데이트로 기본 규칙이 바뀌면, 기본값을 그대로 쓰던 항목만 새 기본값으로 바뀌고 직접 고친 항목은 남습니다. 이력에 "앱 업데이트(규칙 vN)"로 남습니다.

### 7-6. 환류 — 결과 엑셀 → Claude → 규칙 붙여넣기
1. 프로 탭 **[⤓ 결과 엑셀로 내려받기]** (며칠 치를 모으면 더 정확)
2. 선정 규칙 탭 **[개선 요청문 복사]** (지금 규칙 JSON이 함께 복사됨)
3. Claude 대화창에 붙여넣기 + 결과 엑셀 첨부 → 보내기
4. **[Claude 답변 붙여넣기]** → 답변 전체를 붙여 넣고 **[다음]** → 바뀔 항목 확인
5. **[적용]** → 저장되고 변경 이력에 "Claude 개선안 적용"으로 남음

앱의 판단(★·점수·자동 분류)과 담당자의 판단(최종 선택)이 어긋난 곳이 규칙을 고칠 곳입니다.

## 8. 설정 탭

바꾼 값은 **[설정 저장]**을 눌러야 적용됩니다. 모든 값은 이 PC의 config.json에만 저장됩니다.

- **기사 출처**: (●) 구글 뉴스 (키 필요 없음) / ( ) 네이버 (API 키 필요). **[✓] 전문지 RSS 함께 조회** + 지금 쓰는 전문지 요약 + **[전문지 고르기 ›]**
- **네이버 API**: Client ID · Client Secret (출처가 네이버일 때만)
- **보고서**: 메일 제목(`{날짜}` → 261026, 예: `({날짜})언론보도` → `(261026)언론보도`), 보고서 제목(기본: 언론보도 모니터링(임원용))
- **선정 규칙**: **[선정 규칙 열기 ›]**
- **공휴일**(오른쪽): 자동 기간 계산용. 임시공휴일은 `YYYY-MM-DD 이름`으로 한 줄 추가. 2026~2027년이 들어 있습니다.

### 8-1. 전문지 고르기
**[설정] → [전문지 고르기 ›]**
1. 목록: 사용(첫 칸을 눌러 켜고 끄기) · 매체 · RSS 주소 · 연결 확인 결과
2. 추가: 매체 칸(비워도 됨)과 **홈페이지 또는 RSS 주소** 칸에 홈페이지 주소만 넣고(예: `www.aptn.co.kr`) **[＋ 추가]** → `/rss/allArticle.xml`을 붙여 찾아 연결까지 확인하고, 매체 이름도 채웁니다. 이미 있는 매체는 다시 들어가지 않습니다.
3. **[고친 내용 적용] [삭제] [연결 확인 (고른 매체, 없으면 전체)]**
4. **[저장]**

국내 신문사 다수는 "홈페이지 + /rss/allArticle.xml"이 RSS 주소입니다. 안 되면 신문사 홈페이지 맨 아래 RSS 메뉴에서 전체기사 주소를 복사해 넣습니다.

## 9. 문제 해결

| 증상 | 원인 | 조치 |
|---|---|---|
| 처음 실행 때 윈도우 경고 | 코드 서명이 없는 프로그램 | [추가 정보] → [실행], 또는 속성 → 차단 해제 |
| 업데이트 확인 실패 안내 | GitHub 접속이 막힌 PC | 공문 경로에서 새 exe를 받아 바꾸기(설정·기록 유지) |
| "구글 뉴스 호출이 너무 많습니다(429)" | 짧은 시간에 구글에 많이 물음 | 잠시 뒤 다시 조회. 계속되면 키워드 줄이기 |
| 조회가 오래 걸림 | 검색 키워드가 많음(기본 67개) | [■ 정지] 후 기간 줄이기, 효과 없는 키워드 빼기 |
| "전문지 조회 실패: ○○" | RSS 주소가 바뀌었거나 막힘 | 전문지 고르기에서 [연결 확인] → 주소 다시 찾기 |
| "보안 인증서 확인 실패" | 회사 보안장비가 접속을 검사 | 상태줄 메시지를 전산 담당에 전달 |
| 엉뚱한 기사가 추천됨 | 규칙이 그날 기사와 안 맞음 | 결과 엑셀 → Claude 환류로 빼는 말(-○○) 추가 |
| 보고한 기사가 또 나옴 | [④ 보고 완료로 기록]을 안 함 | 보낸 뒤 꼭 기록. 지난 메일은 보고 기록 탭에서 불러오기 |
| 순서를 정했는데 보고서 순서가 다름 | 순서를 정한 뒤 표 머리글을 눌러 정렬됨 | 다시 끌어 놓기로 순서를 정한 뒤 보고서 열기 |

해결이 안 되면 상태줄 문구와 화면을 찍어 전략과로 보내 주세요.

## 11. 확인 필요 사항
- 조회 시간 1~2분은 검색 키워드 67개 기준 **(추정)**.
- 대한경제·한국주택경제신문 RSS 주소 **미확인**(전문지 고르기에서 홈페이지 주소로 확인 가능). 전기신문 RSS는 꺼 둠.
- 그룹웨어 편지쓰기 화면의 붙여넣기 결과(글자 크기 16px)는 실제 그룹웨어에서 확인한 이전 버전 기준.
