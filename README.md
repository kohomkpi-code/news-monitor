# KOHOM 뉴스룸 (NewsMonitor)

구글 뉴스(기본, 키 불필요) 또는 네이버 뉴스에서 키워드별 기사를 모아 중복을 정리하고, 사내메일에 붙여넣을 수 있는
HTML 보고서(제목에 링크)를 만드는 PC 프로그램입니다.

## 설치 (처음 한 번)

1. 오른쪽 **Releases** 에서 최신 버전의 `NewsMonitor_v버전.exe` (예: `NewsMonitor_v0.4.0.exe`)를 내려받습니다.
   - 같은 Release 의 `NewsMonitor.exe` 는 v0.3.1 이하 자동 업데이트용으로 함께 올린 같은 파일입니다.
   - 자동 업데이트를 하면 파일 이름이 새 버전으로 바뀌므로, 바탕화면 바로가기·작업표시줄 고정은 다시 만들어야 합니다.
2. 적당한 폴더(예: `C:\NewsMonitor\`)에 넣고 실행합니다.
   - 윈도우가 "알 수 없는 게시자" 경고를 띄우면 **추가 정보 → 실행** 을 누르세요(서명 없는 프로그램이라 뜨는 안내입니다).
   - exe 옆에 `config.json`, `sent_history.json`, `reports\` 가 자동으로 생깁니다. 이 폴더 안에서 모든 것이 관리됩니다.
3. 기본 출처는 **구글 뉴스**라 설정 없이 바로 **조회** 할 수 있습니다.
   - 네이버를 쓰려면 **[설정]** → '네이버 (키 필요)' 선택 → Client ID / Client Secret 입력 → 저장

## 매일 사용 흐름 — 베이직 탭 (처음 하는 사람도)

1. **① 조회** (기간은 자동: 직전 영업일 오전 9시 ~ 지금)
2. ★추천 5건이 선택된 채로 나온다. ☑ 를 눌러 더하거나 뺀다. 구글에 없는 기사는 **＋ 기사 링크로 추가**
3. **③ HTML 보고서 열기** → [제목 복사]·[본문 복사] → 그룹웨어 편지쓰기에 붙여넣기
4. **④ 보고 완료로 기록** → **보고 기록** 탭에서 날짜별로 확인·취소·보고서 다시 열기

## 매일 사용 흐름 — 프로 탭 (AI 선별까지)

1. 기간(기본: 최근 3일)과 A·B 키워드 확인 → **조회**
   - 표 머리글(등급·키워드·날짜·매체 등)을 누르면 같은 것끼리 모아 정렬, '키워드별' 목록으로 골라 선택·해제
2. **① AI 선별 요청문 복사** → Claude 프로젝트 채팅에 `Ctrl+V` → 전송
3. Claude 답변의 `#선정` 아래 줄을 복사 → **② 선정 결과 붙여넣기** → 붙여넣고 **적용**
4. **③ HTML 보고서 열기** → 브라우저에서 `Ctrl+A` → `Ctrl+C` → 그룹웨어 편지쓰기에 `Ctrl+V` → 보내기
5. **④ 보고 완료로 기록** → 다음 조회부터 오늘 보낸 기사는 자동 제외

> 전문지 RSS 주소(아파트관리신문·한국아파트신문·전기신문)는 개발 환경에서 접속이 막혀 **미확인**이다.
> 조회 뒤 상태 표시줄에 "전문지 조회 실패: ○○"가 뜨면 그 매체 사이트에서 RSS 주소를 찾아 `config.json` 의 `extra_feeds` 를 고친다.

## 새 버전 배포 (관리자용)

1. 수정된 파일을 GitHub 웹 화면에서 업로드하거나 Claude Code 로 push 한다.
2. `version.py` 의 `__version__` 을 올린다(예: `0.1.0` → `0.2.0`). **이 숫자가 바뀌어야 새 Release 가 만들어진다.**
3. `CHANGELOG.md` 맨 위에 변경 내용을 적는다 (Release 설명으로 그대로 들어감).
4. 업로드 후 2~4분이면 **Actions** 탭에서 빌드가 끝나고 **Releases** 에 새 exe 가 올라온다.
5. 사용자 PC 의 앱은 다음 실행 때 새 버전을 알려 주고, 확인을 누르면 스스로 교체·재시작한다.

## 파일 구성

| 파일 | 역할 |
|---|---|
| `app.py` | 화면(GUI). 버튼·표·설정창 |
| `google_news.py` | 구글 뉴스 RSS 조회 (키 불필요), 원문 주소 찾기 |
| `feeds.py` | 전문지 RSS 직접 구독, 키워드 맞추기 |
| `rss.py` | RSS 읽기 공통 부분 |
| `selection.py` | AI 선별 요청문 만들기, 선정 결과 읽기 |
| `naver_api.py` | 네이버 뉴스 검색 API 호출 |
| `dedup.py` | 중복·유사 기사 제거, 제외어 |
| `report.py` | 메일용 HTML 보고서 생성 |
| `history.py` | 보고 완료 기사 기록 |
| `sources.py` | 언론사 도메인 → 매체명 표 |
| `updater.py` | GitHub Release 확인·자동 교체 |
| `config.py` | 설정 파일 읽기/쓰기 |
| `theme.py` | 화면 디자인(색·글꼴·버튼 모양) |
| `result_table.py` | 결과 표(선택 아이콘·정렬·줄 색) |
| `icons.py` | 표·체크 아이콘(그림을 글자로 넣어 둔 것, `tools/make_icons.py` 로 다시 만듦) |
| `assets/fonts/` | Pretendard 글꼴(SIL OFL 1.1, 라이선스 파일 동봉) |
| `version.py` | 버전 번호 (배포 시 여기만 수정) |
| `.github/workflows/build.yml` | GitHub 가 exe 를 자동으로 만드는 설정 |
| `.github/workflows/screens.yml` | 윈도우에서 화면을 찍어 `ci-screens` 브랜치에 올림(개발 확인용) |
| `docs/개발일지.md` | 개발 과정에서 배운 것·결정한 것 기록 |

## 보안 메모

- 네이버 API 키는 이 PC 의 `config.json` 에만 저장되며 GitHub 에는 올라가지 않습니다(`.gitignore`).
- 프로그램은 구글 뉴스(`news.google.com`), 전문지 RSS(`config.json` 의 `extra_feeds`), 네이버 API(`openapi.naver.com`, 네이버 선택 시), GitHub(`api.github.com`, `github.com`)에만 접속합니다.
